永續外牆通風雨幕掛板選型：燒杉（Shou Sugi Ban）vs 紅雪松 vs 深度碳化木

耐久等級標準、防火阻燃評級、天然防腐抗衰、開縫通風雨幕構造與商用木業供應鏈採購指南

發布機構：LAIARC 綠色人居與運算性設計實驗室

1. 天然無化學添加外牆木材的材料物理學

建築外立面圍護體系常年經受嚴酷的環境侵蝕：紫外線（UV）光老化降解、凍融循環熱應力破壞、黴菌孢子附著滋生以及高濕水汽滲透。傳統木質外牆掛板普遍依賴劇毒的化學防腐劑浸漬（如 CCA 銅鉻砷防腐處理或溶劑型防腐塗料），不僅需要頻繁的人工塗刷維護，還會持續向周邊環境釋放揮發性有機物（VOCs）。

相較之下，高性能綠色建築轉而採用熱改性技術與天然耐腐木材掛板。透過受控高溫熱解（Pyrolysis）重塑纖維素微觀結構，或直接採伐天然富含抗腐提取物的優質樹種，這些木材得以在零化學藥劑溶出的前提下，達到歐洲標準 Class 1/2 頂級耐久等級，使用壽命長達 50 年以上。

高溫熱改性與熱解化學控制機制：
• 半纖維素熱分解： 在無氧或低氧窯爐中將木材加熱至 180°C–230°C，使極易吸水的半纖維素分子熱解為非親水性化合物，將木材的平衡含水率（EMC）大幅降低達 50%。
• 生物免疫屏障： 徹底消除木腐真菌賴以生存的親水羥基營養源，從根本上杜絕黴菌滋生，實現無需任何化學防腐劑的永久防腐防蛀能力。

2. 材料核心性能指標橫向評測矩陣

深入橫向比選高溫炭化木（日式燒杉 Yakisugi）、自帶天然防腐提取物的純天然針葉軟木（北美紅雪松）以及工業熱改性碳化木（Thermowood），揭示各材料在美學質感與工程力學上的差異化優勢：

耐久性等級（EN 350-2 標準） Class 1（極強耐久，50 年以上壽命） Class 2（強耐久，30–50 年壽命） Class 1–2（40–60 年壽命）
尺寸幾何穩定性 優異（表面碳化層固化鎖定內部木芯） 良好（極低的乾縮濕脹係數） 卓越（濕脹率降低高達 90%）

3. 通風雨幕構造節點與抗腐固定系統

即使是頂級耐腐木材，如果背部長期積存水分與潮氣，也難逃腐朽隱患。符合建築規範的開縫通風雨幕系統（Ventilated Rainscreen, VRS）將外飾面耐候雨幕與主體結構保溫外護層徹底解耦：

1. 連續通風空氣夾層（20–38 mm）

豎向防腐龍骨木條在板背構建起連續的熱壓對流風道，能在第一時間風乾滲入的風載雨水，並及時導排自牆體內部擴散出來的水蒸氣。

構造規範：底部勒腳進風，屋簷挑簷頂部排風

2. 海洋級緊固連接件（A4 / 316 不鏽鋼）

木材中自帶的天然單寧酸與碳化層對普通電鍍鋅螺釘具備強烈的化學腐蝕作用。必須指定 304/316 奧氏體不鏽鋼專用螺釘或隱蔽式暗扣扣件，防止產生永久性黑斑流痕。

構造規範：優選隱藏式扣件或小帽沉頭專用螺絲
抗紫外線透汽防水墊層規範（WRB）： 當設計帶有板縫間隙的現代開縫式木雨幕時，板後基層必須滿鋪專用的黑色、抗紫外線直射的高分子透汽防水膜（如 DuPont Tyvek ThermaWrap / Pro Clima SOLITEX FRONTA QUATTRO），並在底部勒腳與頂部排風口滿鋪防蟲防鼠金屬通風網。

4. 外牆掛板與緊固系統一級供應鏈名錄

1. 原裝日本燒杉板與歐洲高溫碳化木 中本林業 Nakamoto Forestry / Thermory / Lunawood

  • 原裝正宗日式燒杉外牆板： Nakamoto Forestry Suyaki 素燒（厚重鱷魚皮炭面）、Gendai 現代輕刷、Pika-Pika 雙重拉絲碳化柳杉掛板。
  • 工程級熱改性碳化木型材： Thermory Benchmark 高溫碳化白蠟木/赤松，以及芬蘭 Lunawood Thermo-D 級高溫改性雲杉雨幕條板。
採購管道指引： 透過授權一級進口木業經銷網絡獲取樣品盒、阻燃耐火性能檢驗報告與整貨櫃專案大宗採購物流方案。

2. 耐腐蝕雨幕五金緊固件與耐候防水透汽膜 GRK Fasteners / 辛普森 Simpson Strong-Tie / 杜邦 DuPont

  • 專用結構緊固件： GRK Trim-Head 316 奧氏體不鏽鋼沉頭自攻螺絲、Simpson Strong-Tie Deck-Drive DWP 專用木螺釘。
  • 開縫雨幕透汽膜： 杜邦 DuPont Tyvek UV 黑色耐紫外線防水透汽膜與周邊收口耐候通風防蟲網。
專業供貨通道： 透過建築外圍護材料工程專案集採通道，採購符合嚴格耐腐蝕標準的海洋級不鏽鋼五金與周邊泛水收口配件。

結語： 永續外牆木掛板完美融合了古老的木材表面炭化熱解工藝與當代嚴謹的建築物理學原理。透過採用無化學藥劑添加、尺寸幾何極其穩定的工程木材，並嚴格匹配精密設計的通風雨幕空腔構造，建築得以兼得歲月沉澱的美學尊嚴、出色的抗火耐腐韌性與對自然生態的極致尊重。
